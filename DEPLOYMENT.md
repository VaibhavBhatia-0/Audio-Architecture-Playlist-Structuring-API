# Deployment status

Status as of 24 October 2026 (India Standard Time): **Vercel-ready browser demo;
AWS deployment postponed**. The account owner reports that the required
IAM/OIDC setup is unavailable on their current AWS Free account plan. No live
Vercel URL or AWS endpoint has been verified here.

## Implemented

| Area | Current result |
| --- | --- |
| Playlist engine | Python API: duration-aware beam search across seven energy curves. Hosted browser demo: simpler local optimizer, clearly labeled in the UI. |
| Catalog | 118 deterministic fictional metadata tracks in seven genres, generated by `scripts/seed_catalog.py`. No copyrighted recordings are included. |
| Custom songs | Validated metadata creation, listing and deletion through `/tracks/custom`; local-disk and DynamoDB adapters, plus browser-local offline fallback. New tracks enter genre stats, catalog browsing, exclusion controls and generation. |
| React frontend | Light "cue sheet" design (paper, ink and one vermillion accent; serif headings; ruled sections instead of cards). Scenario starters, lettered builder steps with a sticky summary, custom curve preview, custom-song form, energy chart, tracklist with transitions, synthesized previews, history and export. Visible focus, keyboard-operable chart points, skip link, reduced-motion support and modal focus management. |
| Data/export | Saved playlist snapshots and history; Extended M3U, JSON and CSV. Exports are built only from the stored playlist with the requested ID; client-supplied playlist bodies are ignored. CSV export protects against spreadsheet formula interpretation. Crossfade is a scheduling value, not rendered audio. |
| AWS infrastructure template | Terraform defines API Gateway, Lambda, two DynamoDB tables, S3, CloudFront, CloudWatch, IAM and budget alerts. No workflow currently deploys or destroys these resources. |
| Documentation | Technical design document, mathematical formulation, API specification, measured test results, AWS setup and release checklist. |
